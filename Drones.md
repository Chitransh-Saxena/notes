# Drones

FPV. Building, tuning, breaking, repairing, occasionally flying well.

## Threads

- Build logs — what went into each quad and what I'd change
- Tuning notes — filters, rates, what actually made a difference
- Field notes — conditions, batteries, what broke

> [!tip] Why a vault suits this
> A build log is mostly links: the same motors, the same stack, the same
> mistakes across different frames. Writing a part once and embedding it in every
> build that uses it beats copying it five times.
