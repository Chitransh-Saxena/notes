# notes

My public working notes. This repository *is* an Obsidian vault — open the folder
in Obsidian and it works.

It's published as a website with [Obsidiary](https://github.com/Chitransh-Saxena/obsidiary).

There is no build here on purpose: the site is a separate project that reads this
repository. Writing a note and pushing it is the entire workflow.
